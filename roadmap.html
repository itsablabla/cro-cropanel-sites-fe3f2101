The four-week roadmap

Ordered by severity first, then by effort, so week one always ships something reversible. Each item links to its specification.

Week 1
Ship the reversible urgent fixes

Sequence, do not batch Shipping every change at once makes it impossible to attribute a result to a cause. Where traffic allows, run each item as its own test. Where it does not, ship in the order above and record the date of each change so the trend can be read against it.
